solicitacao_dieta_especial
==========================

Submódulo de solicitações de dieta especial. Contém o modelo central
:class:`SolicitacaoDietaEspecial` e os catálogos de alergias/intolerâncias,
classificações, motivos de negação e motivos de alteração de U.E., além dos
endpoints de API responsáveis pelo fluxo de autorização, cancelamento,
inativação e geração de relatórios.
